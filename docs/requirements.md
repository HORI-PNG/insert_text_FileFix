# File Fix 要件定義書（v1.0 確定版）

> **書き方のルール**
>
> - 各要件には ID（`FR-01` など）を付ける。「FR-03 を変更」のように ID で指示できます
> - 優先度は **Must**（必須）/ **Should**（できれば）/ **Could**（余裕があれば）の3段階
> - `（案）` は Claude が補った内容です。違えば書き換えてください
> - 決め方の経緯は「10. 決定事項の記録」にあります

---

## 1. 概要

| 項目     | 内容                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------ |
| 目的     | ファイル（またはフォルダ内の全ファイル）で、検索文字列を含む行の一行上に、同じインデントで任意の文字列を挿入し、別ファイルとして保存する |
| 利用者   | 自分のみ                                                                                         |
| 利用環境 | Chrome / Edge の最新版。WSL（Ubuntu）上のファイルを扱うときは、**WSL の中の Chrome（WSLg）**で開く（Windows の Chrome / Edge では `\\wsl.localhost\...` のフォルダを選べないため） |
| 起動方法 | ターミナル1：`cd ~/insert_text_FileFix && npm run dev` ／ ターミナル2：`google-chrome http://localhost:5173` |
| 形態     | ブラウザだけで動く Web アプリ。サーバーなし                                                      |

## 2. スコープ

### やること

1. 「ファイルを選ぶ」ボタンで、ファイルを1つ選んで処理する
2. 「フォルダを選ぶ」ボタンで、フォルダ内（サブフォルダ含む）の指定した拡張子のファイルをすべて処理する
3. 「出力先を選ぶ」ボタンで、保存先フォルダを選ぶ
4. 「挿入開始」ボタンで、挿入と保存を一度に行う
5. 処理中は SVG のローディングアニメーション、完了時は SVG の完了アニメーションを表示する

### やらないこと

- 正規表現での検索、元に戻す（Undo）、ログイン
- プレビュー、挿入箇所の強調
- パスの貼り付けでファイルを開くこと（ブラウザの制限で不可）
- 元のファイルへの上書き保存
- 「最初の1箇所だけ」挿入する機能
- ファイル名の手入力

## 3. 機能要件

### 3.1 入力（何を処理するか）

| ID    | 機能               | 詳細                                                                                                                         | 優先度 |
| ----- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------- | ------ |
| FR-01 | ファイルを選ぶ     | OS のダイアログでファイルを1つ選ぶ。選んだファイル名を表示する                                                               | Must   |
| FR-02 | フォルダを選ぶ     | OS のダイアログでフォルダを選ぶ。**サブフォルダの中まで**対象にする。対象ファイルの件数を表示する                             | Must   |
| FR-03 | 拡張子の指定       | フォルダ選択時の対象拡張子を、**チェックボックス**（`.ts` `.tsx` `.js` `.jsx` `.py` `.java` `.txt` など）と**自由入力**で指定する | Must   |
| FR-04 | 除外フォルダの指定 | 処理しないフォルダ名を指定できる。初期値（案）：`node_modules` `.git` `dist` `build` `.venv` `venv` `__pycache__`。追加・削除できる | Must   |
| FR-05 | `.class` の除外    | `.class` はバイナリのため、常に対象外にする                                                                                  | Must   |

### 3.2 検索と挿入（何をするか）

| ID    | 機能               | 詳細                                                                                                     | 優先度 |
| ----- | ------------------ | -------------------------------------------------------------------------------------------------------- | ------ |
| FR-10 | 検索と挿入の「組」 | 「検索文字列（1行）＋挿入文字列（複数行可）」を1組とし、**＋ボタンで組を増やせる**。不要な組は削除できる | Must   |
| FR-11 | 検索               | 検索文字列を**含む**行を対象にする（部分一致）                                                           | Must   |
| FR-12 | 大文字・小文字     | 区別する（`Return` と `return` は別物）                                                                  | Must   |
| FR-13 | 挿入               | 対象行の一行上に、その組の挿入文字列を追加する。一致した箇所すべてに挿入する                             | Must   |
| FR-14 | 重なり             | 1つの行が複数の組に一致したら、**一致した組すべて**の挿入文字列を、組の順番（上から）で挿入する          | Must   |
| FR-15 | インデント         | 挿入行に、対象行と同じ先頭の空白（スペース・タブ）を付ける                                               | Must   |
| FR-16 | 複数行の挿入       | 挿入文字列が複数行なら、すべての行に同じインデントを付ける                                               | Must   |
| FR-17 | 空行の挿入         | 挿入文字列が空なら、**空行を1行**挿入する。（案）空行にはインデントを付けない（行末に空白を残さないため） | Must   |

### 3.3 出力（どう保存するか）

| ID    | 機能             | 詳細                                                                                       | 優先度 |
| ----- | ---------------- | ------------------------------------------------------------------------------------------ | ------ |
| FR-20 | 出力先を選ぶ     | OS のダイアログで出力先フォルダを選ぶ（ファイル・フォルダどちらのモードでも）              | Must   |
| FR-21 | ファイル名       | `元の名前_fix.拡張子`（例：`app.ts` → `app_fix.ts`）                                       | Must   |
| FR-22 | フォルダ構造     | フォルダ選択時は、出力先に**同じフォルダ構造**を作る（例：`src/utils/a.ts` → `出力先/src/utils/a_fix.ts`） | Must   |
| FR-23 | 名前の重複       | 出力先に同名ファイルがあれば `_fix(2)` `_fix(3)` … と番号を付ける                         | Must   |
| FR-24 | 一致なしのファイル | （案）一致が0件のファイルは**保存しない**。一覧に「一致なし」と表示する                  | Must   |
| FR-25 | 改行コード       | 元の改行コードを保つ（LF は LF、CRLF は CRLF のまま）                                      | Must   |

### 3.4 実行と結果

| ID    | 機能               | 詳細                                                                                                   | 優先度 |
| ----- | ------------------ | ------------------------------------------------------------------------------------------------------ | ------ |
| FR-30 | 挿入開始           | 「挿入開始」ボタンで、挿入と保存を一度に行う                                                           | Must   |
| FR-31 | ローディング表示   | 処理中は `loading.svg` を表示する。**最低 0.8 秒**は表示する                                           | Must   |
| FR-32 | 完了表示           | 完了したら `done.svg` を表示する                                                                        | Must   |
| FR-33 | 保存したファイル一覧 | ファイル名・出力先フォルダ内の場所・挿入件数を一覧表示する。スキップ件数・一致なし件数も表示する     | Must   |
| FR-34 | 履歴の注意書き     | 一覧の下に「この履歴は、ブラウザのリロード時に削除されます」と表示する                                 | Must   |

## 4. 画面

### 4.1 部品

> 新しい部品と id は、実装計画（Plan）で Claude が提案します。

### 4.2 状態ごとの表示

| 状態                     | 結果欄の表示                         | 挿入開始ボタン                                    |
| ------------------------ | ------------------------------------ | ------------------------------------------------- |
| 起動直後                 | 使い方の説明                         | 押せない                                          |
| ファイル／フォルダ選択後 | 選択したファイルの一覧と件数         | 出力先も選ばれていれば押せる                      |
| 処理中                   | ローディングアニメーション           | 押せない                                          |
| 完了後                   | 完了アニメーション＋保存したファイル一覧＋注意書き | 押せる（条件を変えて再実行できる） |

## 5. 処理の流れ

```
起動
 → [ファイルを選ぶ] or [フォルダを選ぶ]（フォルダなら拡張子・除外フォルダを指定）
 → 検索と挿入の組を入力（＋で追加）
 → [出力先を選ぶ]
 → [挿入開始] → ローディング → 完了アニメーション → 保存したファイル一覧
```

## 6. エラー・例外時の動作

| ID    | 状況                               | 動作                                                                           |
| ----- | ---------------------------------- | ------------------------------------------------------------------------------ |
| ER-01 | ダイアログでキャンセルした         | 何もしない。エラーも出さない                                                   |
| ER-02 | 入力・出力先が未選択               | 挿入開始ボタンを押せなくする                                                   |
| ER-03 | 検索文字列が空の組がある           | 「検索文字列を入力してください」と警告し、処理しない                           |
| ER-04 | 挿入文字列が空                     | エラーにしない。空行を挿入する（FR-17）                                        |
| ER-05 | 一致する行がなかった               | 全ファイルで0件なら「見つかりませんでした」と表示                              |
| ER-06 | 非対応ブラウザ（Firefox / Safari） | 「このブラウザは対象外です。【対象】Chrome または Edge」と表示し、操作できなくする |
| ER-07 | 読めないファイル（画像など）       | ファイル選択時：「対象ファイルを選択してください」と表示。フォルダ選択時：黙ってスキップし、最後に「〇件スキップ」と表示 |

## 7. 非機能要件

| ID    | 項目           | 内容                                                                                       |
| ----- | -------------- | ------------------------------------------------------------------------------------------ |
| NF-01 | 文字コード     | UTF-8 のみ対応                                                                             |
| NF-02 | 改行コード     | 元の改行コードを保つ（FR-25）                                                              |
| NF-03 | ファイルサイズ | 上限は設けない                                                                             |
| NF-04 | デザイン       | Apple の製品ページ風。白・灰色と、アクセントに**千歳緑 `#316745`**。パソコンでは一画面に収める |
| NF-05 | 言語           | 画面の文言は日本語                                                                         |

## 8. 技術構成

| 項目         | 内容                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| ビルド       | Vite（Vanilla + TypeScript）                                               |
| CSS          | Tailwind CSS v4（`@tailwindcss/vite`）                                     |
| ファイル操作 | File System Access API（型：`@types/wicg-file-system-access`）             |
| ファイル構成 | `src/logic.ts`：挿入ロジック（DOM に触れない） / `src/main.ts`：画面の操作 |
| 方針         | ロジックと画面操作を分ける。部品の取得は `getEl()` を使う                  |
| アニメーション | `public/loading.svg`、`public/done.svg`（作成済み）                      |

## 9. 受け入れテスト

- [ ] T-01：ファイルを1つ選び、出力先を選んで挿入開始すると、出力先に `元の名前_fix.拡張子` ができる
- [ ] T-02：スペース4つでインデントされた行に一致すると、挿入行にもスペース4つが付く
- [ ] T-03：タブでインデントされた行では、挿入行にもタブが付く
- [ ] T-04：組を2つ作り、同じ行に両方が一致すると、組の順番で2つとも挿入される
- [ ] T-05：挿入文字列が空の組では、空行が1行挿入される
- [ ] T-06：フォルダを選ぶと、サブフォルダの中の対象拡張子のファイルも処理され、出力先に同じ構造で保存される
- [ ] T-07：`node_modules` など除外フォルダの中は処理されない
- [ ] T-08：出力先に同名ファイルがあると、`_fix(2)` が付いて保存される
- [ ] T-09：CRLF のファイルは、CRLF のまま保存される
- [ ] T-10：ダイアログをキャンセルしても、エラーにならない
- [ ] T-11：処理が一瞬で終わっても、ローディングが 0.8 秒以上表示される
- [ ] T-12：Firefox で開くと、対象外のメッセージが表示される

## 10. 決定事項の記録

| No   | 質問                                   | 決定                                                       |

| Q-01 | 「完全一致」の意味                     | 部分一致（含む）に変更                                     |
| Q-02 | 複数の検索文字列の入力方法             | ＋ボタンで「検索＋挿入」の組を増やす                       |
| Q-03 | 検索文字列と挿入文字列の関係           | 組ごとに別々の挿入文字列                                   |
| Q-04 | 大文字・小文字                         | 区別する（ユーザー記入の FR-04 より）                      |
| Q-05 | 「最初の1箇所だけ」の範囲              | 機能ごと削除                                               |
| Q-06 | パスの貼り付け                         | やめる                                                     |
| Q-07 | フォルダの範囲                         | サブフォルダまで。除外フォルダを指定できる                 |
| Q-08 | 除外フォルダ                           | 初期値あり・自由に変更できる（Q-07 に統合）                |
| Q-09 | 拡張子の選び方                         | チェックボックス＋自由入力                                 |
| Q-10 | `.class`                               | 対象外                                                     |
| Q-11 | 対象外ファイル（フォルダ時）           | スキップして件数を表示                                     |
| Q-12 | 保存先の選び方                         | どちらのモードでも出力先フォルダを選ぶ                     |
| Q-13 | ファイル名の入力欄                     | 付けない。すべて `_fix` の命名規則で                       |
| Q-14 | 出力のフォルダ構造                     | 同じ構造                                                   |
| Q-15 | 上書き保存                             | 必要ない                                                   |
| Q-16 | 処理の流れ                             | 挿入開始で、挿入と保存を一度に行う                         |
| Q-17 | 同名ファイル                           | `_fix(2)` のように番号を付ける                             |
| Q-18 | SVG アニメーション                     | Claude が作成済み（3つの点が大小／グッドの手が飛び出す）   |
| Q-19 | ローディングの最低表示時間             | 0.8 秒                                                     |
| Q-20 | 一覧の表示内容                         | ファイル名・場所・挿入件数                                 |
| Q-21 | 状態ごとの表示                         | 4.2 の通り                                                 |
| Q-22 | 色                                     | 千歳緑                                                     |
| Q-23 | 改行コード                             | 元のまま保つ                                               |
| Q-24 | 警告の文言                             | 「入力してください」に修正                                 |
| Q-25 | 挿入文字列が空                         | 空行を挿入する                                             |
| Q-26 | やらないこと                           | 正規表現・Undo・ログインはやらない                         |
| Q-27 | 1行が複数の組に一致                    | 一致した組すべてを、組の順に挿入                           |

### 残っている（案）

> 違えば書き換えてください。何も書かなければ（案）の通りに実装します。

- **FR-17**：空行にはインデントを付けない
- **FR-24**：一致が0件のファイルは保存しない
